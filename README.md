# Login Trap - Phishing Awareness Demonstration

## About
Login Trap is a cybersecurity awareness micro-project that demonstrates
how a fake login page can look like a real website.

The project is designed for educational purposes to help students
identify phishing pages and protect their personal information.

## Technologies
- Python
- Flask
- HTML
- CSS

## Main Features
- Fake student login page
- Safe phishing simulation
- Phishing awareness message
- URL awareness
- Password safety tips
- Responsive interface

## Safety
This project is only a simulation.
Usernames and passwords are NOT stored, printed, or sent anywhere.
